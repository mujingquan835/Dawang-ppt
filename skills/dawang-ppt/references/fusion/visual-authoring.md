# Dawang补充做法

排版前必读。原规则是设计依据；本文补原规则未写到的执行方法，均来自用户反馈过的制作轮次。与原规则或用户要求冲突时，按原规则和用户。某次认可的配色、字体、深色背景或页序只属于当次，不是默认外观。

## 不用卡片时靠什么建立层次

原规则禁止卡片和无意义装饰，是要求换一种方式建立层次，不是只剩文字和细线。每页至少用下列一种手段承担主视觉，并写进 `visualDecision.layout`：

- **尺度对比：** 核心数字或关键词放大到正文 3 倍以上，占据画面主要位置；其余信息明显退后。
- **结构图：** 流程、分支、层级、对应关系用 shape / vector / line 画出节点与连接；说明文字与节点按同一坐标对齐，不靠文字里的“→”。
- **证据画面：** 截图、照片放到关键区域看得清的面积；整图太小就局部放大，用框线或引线指向对应说明。
- **视觉母题：** 全稿共用一种可识别的图形语言（设计过的编号节点、色带、角标等），每页按内容变化。普通文字“01 / 02”不算母题。
- **色面分区：** 用大面积底色或色带划分主次区域（不是带描边的小卡片）。

用同一个函数批量生成结构相同的各页就是模板化：先按每页内容关系决定构图，再写元素。只有文字和细线的页面 `make` 会警告 `visual-text-only`；全稿重点都是整块标题会被拦下（`visual-focus-all-titles`）。

## 标题内的重点

先按 场景规则定标题的职责（管理汇报：陈述状态或结论；培训：预告学习收获等），再找标题里最值得记住的结论、状态或数值作为重点，其余是引导或解释。

- 重点与引导语要在实际尺寸上看得出主次：字号、字重、颜色、字体、断行任选组合，用同一文字元素的 runs 实现；确有构图需要可拆成多个元素。
- 动作罗列（“梳理、验证、归类、完善”）不是结论；短标题或整体已足够有力时可统一样式，记录理由。
- 中文艺术字体须字符完整、实际加载；不把某次用过的思源 Heavy、金色或断行固化成模板。改字后检查断行、文本框高度和保存重开后的分段样式。

## 数据指标的组合与对应

- **完整成组：** 数值、单位、指标名称一次扫视读懂；单位贴近数值，组内距离明显小于组间距离。可用 runs 保持数字与单位关系，或按实际字宽与基线定位独立元素。
- **一致节奏：** 并列指标的名称位置、数值层级、单位基线与间距一致；不同单位的数量不暗示可比较高低。
- **对应真实：** 指标与正文确有逐项对应才用邻近、对齐或连线表达；仅因都是三项而行对齐，会暗示不存在的对应。
- **限定可见：** 单位、时期、口径、来源及虚构/示例/历史状态清楚可读并标明适用范围。

## 大数字与序号的排版

| 数字角色 | 排版决定 | 复核重点 |
|---|---|---|
| 核心指标或主要发现 | 数值承担视觉重量，名称与口径靠近；辅助单位通常缩小或减轻 | 第一眼读出完整数值及意义，口径未被挤掉 |
| 并列数量摘要 | 同等层级、同一基线与单位策略；不因位数不同改字号 | 节奏统一，不暗示可比较 |
| 序号、年份、步骤 | 服务导航，通过字重、色彩、位置与业绩指标区分 | 01/02 不被误读成统计结果 |

混合字号后检查真实行盒与基线；不为版面自行四舍五入或改换单位。网格、环形、条形要有明确分母与编码依据。

## 对齐线与容器内的平衡

同组文字先定共同对齐线；错位只在有助于层级或阅读顺序时用，字体边白造成偏差可小幅光学校正。确需容器时，把标题、说明和标记当一个内容组，按实际字形范围平衡上下留白，不对过高的文本框做几何平均。文案或字号变化后重新检查。（原规则多数场景禁止用卡片建立层级，先用线条、留白与字号对比。）

## 图片与说明

- 先确定图片支持哪句说明，再决定整图、局部或组图；解释靠近对应区域。整图缩小后关键文字不可读时用局部放大或调整面积，需要观众理解的动作与结论用可编辑正文表达。
- 取景前核对源图尺寸与主体位置；裁切后检查关键文字完整、相邻画面未混入，保留原图。历史界面、合成示例等状态就近说明。
- 没有用户图片时：真实对象/界面用已授权原图；步骤、组成、依赖用可编辑文字、线条、形状构成示意；场景氛围按授权搜索或生成并标明属性。生成图和示意图不能冒充实测结果、真实案例或产品界面。

## 借鉴外部视觉参考

用户要求借鉴某个组件、动效或风格时，先看来源的真实画面，提取与本页读者任务有关的关系（例如：文字承担主视觉时，引导语、关键词、解释分担职责；界面承担证据时，用角标或框线界定真实目标、引线连到就近标签），在提纲记录如何落实，再做代表性单页对照。只改颜色、字号或分隔线不算借鉴成功。外部代码、字体或资产的复用另按其授权处理。

**已认可案例（2026-11-02）：** 稳定王“先选定拍摄主体”单页借鉴 TypeShift 的错位文字层级与 UICallout 的区域指示关系，独立制作静态可编辑页面，用户反馈“效果认可”。可迁移的是语义层级和图文对应，不是深蓝底、左右分栏、118px 字或固定强调色。
