# 版式案例：按信息关系借鉴

需要具体版式参照时读取，使用边界统一见[dashi 参考附录](visual-authoring.md#dashi-参考附录)。先看实际渲染页面，再提取适用关系；风格总览、页面名称和 props 元数据只用于定位候选，不能替代看正文页面。下面的组件编号是研究索引，不是新稿的固定选页结果。

## 按当前表达寻找参照

| 当前表达 | 可参照的关系 | 先核对 |
|---|---|---|
| 一个值得记住的观点 | 主张与字体性格 | 主张、解释和来源的主次 |
| 解释完整动作顺序 | 流程与解释层 | 必需步骤、条件和说明的对应 |
| 汇总多条行动或要点 | 窄主张与宽条目 | 总结与条目不重复，条目容量足够 |
| 找到界面中的操作 | 界面总览与操作局部 | 原图来源、必要标签与局部可读性 |
| 看清一个对象的组成或范围 | 对象与就近标注 | 指示线指向正确，保留关系与限定 |
| 由真实场景引出共同观点 | 通栏画面带与说明 | 图片主次、取景、对照口径与文字位置 |
| 核对指标并理解结论 | 数据主区与解释区 | 数据口径与结论依据，视觉权重符合重要性 |

这里只用于定位可借鉴关系。图片、数据或阅读场景不适合时继续自主构图；[离线案例示意](visual-casebook.html)只展示部分关系。[配色案例](palette-cases.md)单独说明颜色职责，任何版式都可按品牌或本次方向重新配色。

## 主张与字体性格

研究参照：`theme11_page010`。该页面将较短主张放在主区域，以展示字体、符号、辅助信息及留白共同形成视觉中心。可借鉴标题与正文的字体职责、主张的行长和位置，以及辅助层与主张的距离。先由材料确定主张，再选择适合受众的展示字体；关键词继续按语义强调。

人物署名、引号或装饰符号依据材料与语境判断。引用符号不制造名人背书；案例原有品牌、人物、标语和背景素材不继承。文字主视觉的质量取决于字体和构图配合，单纯放大同一种黑体不等于完成少字页设计。

## 流程与解释层

研究参照：`theme11_page023`。该页面先给出流程的整体主张，中央承载步骤链，另一区域安排相关说明。可借鉴主张—步骤—解释三个阅读层的空间分配：读者既能看清顺序，也能查到必要动作或条件。

按已有材料补足对应说明。只有步骤名称时可做简短流程，不编造执行细节填满页面。步骤间距与标签自然宽度协调，重要步骤可以获得视觉优先权，所有必需步骤保留。自主设计用开放文字、线条或其他合适关系表达，不把原版卡片结构自动迁入。

## 窄主张与宽条目

研究参照：`theme11_page007`。该页面的较窄主张区与较宽条目区形成面积对比；编号、条目标题、解释和分隔节奏建立稳定阅读路径。可用于要点总览、动作核对或说明性列表，按材料调整栏宽与行数。

主张区负责概括，条目区负责支持和执行，避免两侧同权长段互相重复。解释紧邻对应条目，行高随内容安排，不能为了模仿整齐而统一缩字。编号表示顺序或索引，不暗示数据排名。

## 界面总览与操作局部

当读者既要认清产品形态，也要理解具体操作时，可将完整界面与同一原图的关键局部并置：总览保留上下文，局部让操作、控件或范围清晰可读，正文就近解释。用标注或连接表达两者的来源关系，避免将放大局部误看成另一个操作状态。

控件截图支持的是操作说明；版本和效果记录分别表达。含文字的局部保留条件与关键标签，历史界面说明其适用版本。静态界面或场景图不足以证明动态效果时，保留必要限定。本案例不要求每个产品页都采用总览加局部，也不要求每张图片只能使用一次。

## 对象与就近标注

研究参照：PPT-master 图文展示的中心对象标注页，以及本轮本机构图范围示意。一个对象承载主要信息，相关说明靠近具体部位，用短线或位置关系连接；适合组成、范围、操作区域或局部解释。区域的大小、边界和标注由事实决定，说明图需标明其示意用途，不把绘制比例当实测数据。

保留对象和标注的空间，让读者能从整体进入细节；解释较多时可用边栏或分组。中心放射、左右或上下标注均可，避免为对称而绕线、制造不存在的部件，或把所有说明都挤进对象内部。

## 通栏画面带与说明

研究参照：PPT-master 的图片带构图方法，以及本机既有汽车场景取景。图片形成连续视觉区域，主张与支持说明沿其上方、下方或已确认的安静区域组织，适合由场景引出一个共同观点。原图比例、主体位置与支持信息决定图片带的高度和多图数量。

多图共用高度、取景尺度和间隔有助于形成整体；重要性不同则采用有主次的面积。不因横向排列就宣称它们构成时间顺序或前后对照。包含关键文字或不可裁证据时保留完整信息；压字需要检查背景与主体，必要时将文字移到独立区域。

## 数据主区与解释区

将真正需要核对的数据、图表或表格置于主要区域，结论与必要解释靠近相关数据。主指标与支持项的面积按决策重要性分配；并列指标才采用同权呈现。图表不能为配合装饰比例而改变数值含义，来源、时期和单位随相应数据呈现。

## 不同内容的研究参照

theme07_page006 展示摘要、重点与数据证据如何分工；theme07_page015 展示主张与支撑要点的关系；theme07_page046 展示章节定位与关系图的面积配置。无对应数据时只提取空间与层级关系，不复制图表、比例或案例数字。也不将其中某种配色设为全局默认。

## 使用边界

这些案例覆盖部分表达关系，不是有限的版式菜单。当前页不适用时回到材料与场景规则自主设计。设计依据是 Kimi 原文，案例只作参照，不另建流程。
