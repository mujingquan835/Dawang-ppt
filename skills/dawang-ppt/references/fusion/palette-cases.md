# 配色参考：dashi全主题与补充案例

需要配色参照时读取，使用边界统一见[dashi 参考附录](visual-authoring.md#dashi-参考附录)。参考范围包括[dashi全部已登记主题](dashi-theme-references.md)、按主流程已读取的规则、产品或真实图片的视觉语言，以及自主配色。下方四组只是补充示例，不是候选全集或默认推荐清单。

本文件说明颜色职责与补充色值；原版主题的发现、页面研究与来源核对由上述主题索引维护。把所需的背景、主文字、强调、辅助与结构面职责放回本次逐页提纲，与[版式案例](layout-cases.md)分别借鉴、组合。

[打开参考索引与补充示意](visual-casebook.html)：上部列出当前dashi主题入口，下部四组色块与合成构图帮助理解颜色职责；索引文字不是原主题预览，补充示意也不替代当前页实际看图。

## 四组补充示例

| 案例 | 背景 / 主文字 | 强调 / 辅助文字 / 结构面 | 适用表达与调整 |
|---|---|---|---|
| 墨色与暖金 | `#1B1D1A` / `#F4F1E8` | `#E8BC60` / `#AFB2A7` / `#30332D` | 产品定位、重点主张；金色可进入关键词或有意义的大色面。细节较多的说明可换浅背景并重新核对文字对比 |
| 纸白与松绿 | `#F3F3EA` / `#19231F` | `#23533F` / `#5D6A61` / `#D7E1D6` | 操作解释、范围关系、自然或社区主题；绿色承担关系和重点，浅绿面承载上下文，避免把所有普通信息都编码为成功状态 |
| 冷白与深蓝 | `#F3F6FB` / `#1D2E4A` | `#285EA8` / `#58677D` / `#DFE8F5` | 数据复盘、知识讲解和需要核对的材料；深蓝组织标题，蓝色区分当前重点。分类或状态需要额外颜色时依语义补充 |
| 暖纸与赭色 | `#F5EFE6` / `#342B25` | `#8C4E35` / `#6D625B` / `#E8D9C9` | 编辑式叙述、文化内容或温和收束；用赭色连接重点词和细线，保留文字层级，避免全页相近棕色失去主次 |

前两组结合本轮本机产品与构图样稿整理；后两组是受浅底数据页和编辑式页面启发的参考色值，未经过所有主题或现场投影验收。色值不是来源模板的精确复刻，也不代表用户已认可每种新组合。

## 迁移到当前页面

把参照转换为本次页面的颜色职责。例如强调色在观点页可突出关键词，在关系页可标识选区，在数据页承担当前重点；这些用途按内容变化。需要明暗切换时保留可辨认的强调与结构关系，分别核对背景上的文字，不直接整套反相。

图片保留必要的自然色与真实状态。可从已有截图或照片提取适合的色彩联系，也可用中性背景协调；真实红色警告、数据分类或品牌标记保持其含义。图片里的文字和复杂底图上的文字需实际看图复核。

全稿依内容安排颜色面积与密度。相同颜色不等于每页相同布局；更换配色也不代表构图已经改变。局部改标题时只处理授权范围，已确认方向直接沿用。
