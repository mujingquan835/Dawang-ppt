# 复核清单

看图检查先执行原规则 step4 的 7 项（图片清晰不变形、文字不压关键画面、不出界、对比足够、排版统一、不溢出、不被遮挡），再对照所读场景文档逐页核对，最后补充下列 Dawang 检查。发现问题先调整内容取舍与构图，再调字号；同一问题三轮仍未解决时提供证据与选项。程序零溢出、关键词齐全不代表通过；用户效果认可另记。

## 内容表达复核

- 只读标题能否理解全稿主线与各页作用？场景要求结论标题时，标题是否真的陈述了状态或结论。
- 原稿中准确有力的表达是否在精简中被削弱；重点句是否具体，去掉项目名后是否只剩通用赞美。
- 主张是否有事实、机制或例子支撑；截图、图注或附件是否成了某项主要价值的唯一载体。
- 精简后是否丢掉关键分支、条件、异常或待核状态；是否把“支持某功能”写成“必然达到效果”。
- 文案改写（见[文案编辑](content-editing.md)）是否让主张更明确、更具体；只换同义词或缩字不算改进。

## 标题与视觉组织复核

- 第一眼看到的是否为本页重点；计划强调的部分在实际尺寸上是否看得出主次，完整句能否顺读；字体实际加载、字符完整。
- 对照 `visualDecision` 与清单中 applied 项：截图上是否真能看到声明的效果。
- 连翻全稿：节奏、明暗与构图变化是否有内容依据；已选配色的颜色职责是否一致。
- 借鉴外部参考时：是否改变了主次、面积或图文关系，而非只有颜色与装饰；角标/框线是否对准真实目标。

## 数据呈现复核

- 能否一次读出数值、单位与名称；单位是否游离，组内距离是否明显小于组间距离。
- 并列指标节奏是否一致；不同单位是否被画成可比较大小；指标与正文的对应是否有事实依据。
- 大数字按角色分配主次（见[大数字与序号](visual-authoring.md#大数字与序号的排版)）；序号与统计结果区分。
- 单位、时期、口径、来源和虚构/示例状态是否完整可读，适用范围明确。

## 布局与工程复核

| 层次 | 记录 |
|---|---|
| 程序检查 | readiness、finiteBounds、coverage、浏览器异常、对比度、不支持项；规则清单与视觉决定检查 |
| 独立复核 | 复核者、轮次、每轮 fail 与修正 |
| 看图检查 | 全稿节奏、逐页构图、截图可读性、取景、修正轮数 |
| 默认交付 | 仅一个 HTML，离线编辑与快照一致；其他格式用户按需导出 |
| 用户认可 | 只记录用户实际给出的意见 |

截图型 PDF 为整页栅格、文字不可选；PPTX 报告声明/实际字体、回退与未嵌入，本机字体存在不代表别的电脑可用。完整导出回归、LibreOffice 渲染与 PowerPoint 打开属于版本验收，不在每份稿件上重复。
