# 视觉评审与交付验收

先看全稿节奏，再逐页检查读者任务、结论、证据、关系、字体层级、图片主体和密度。按实际读取的原规则与用户材料复核；原样模板对照原截图，不把自主设计称为官方复刻。

QA与导出共用readiness：字体/图片完成、有效且稳定尺寸、有限测量值、导航就绪。零scale、坏图、新制作缺字体或不支持的信息内容明确报告，不靠固定屏幕宽度或假等待绕过。旧工程的字体回退警告与新制作严格字体检查分别记录。

检查全部必需事实/媒体、文字溢出和重叠，查看全稿总览与可疑页原尺寸截图。先调整空间、层级与构图；超量则提出拆页或精简重复表达选项，不删必需事实或无限缩字。同一问题最多三轮有依据的修正，仍未解决时提供证据与选项。

| 层次 | 必须记录 |
|---|---|
| 程序检查 | readiness、finiteBounds、coverage、浏览器异常、不支持项 |
| 内容判断 | 对照原稿、数据口径、结果与投入、主次、来源与限制 |
| 看图检查 | 全稿节奏、逐页构图、截图可读性、取景、修正轮数 |
| 编辑回环 | 改字/强调、位置或换图、撤销重做、保存重开 |
| 多格式交付 | 同revision HTML/PDF/PPTX、原生文字/形状、裁切与包内引用 |
| 客户端 | LibreOffice独立渲染、PowerPoint打开/编辑/保存重开分别列证据 |
| 用户认可 | 只记录用户实际给出的意见；代码通过、继续开发不自动等于视觉认可 |

截图PDF明确整页栅格化、文字不可选择。PPTX报告声明/实际字体、回退、未嵌入及目标环境未验证；本机字体存在不代表别的电脑可用。截图内文字仍为图片内容。保留差异与失败日志，不用重新生成的成功结果覆盖原问题记录。
