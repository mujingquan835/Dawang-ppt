# 七场景内容指导
| 场景 | 读者任务 | 建议叙事与证据 |
|---|---|---|
| 分析决策 | 判断原因与选项 | 结论、口径、证据、归因、约束、建议；假设和事实分开 |
| 商业提案 | 判断价值与投入 | 问题、对象、方案、价值依据、成本、实施与决策 |
| 管理汇报 | 判断完成情况与支持事项 | 完成结论、实际与目标、差异、项目证据、纠偏、负责人日期、决策请求；目标缺失不伪造 |
| 学术研究 | 判断可信度与贡献 | 问题、既有依据、方法、样本、结果、不确定性、局限与引用 |
| 教育培训 | 理解并迁移知识 | 学习目标、概念关系、示例、步骤、比较、练习、回顾；分段说明而非过量段落 |
| 技术工程 | 判断方案与实现约束 | 架构、接口、依赖、流程、权衡、故障与验证证据 |
| 品牌创意 | 理解主张与形成记忆 | 主张、场景、视觉证据、叙事节奏与行动；不把装饰当结果 |
四种设计方向：自主设计、完整设计规范、指定原样模板、参考风格迁移。方向不改变事实、局部编辑边界与已确认页数。场景指导不能强行生成缺失的目标、转化率、负责人或时间。
