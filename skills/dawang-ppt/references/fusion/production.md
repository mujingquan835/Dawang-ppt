# 制作逻辑
先完整读取材料，盘点来源、事实、单位、时期与必需图片。明确受众、用途、主场景与固定页数；区分新建、局部修改、重构、原样模板。未经授权不补业绩、目标、因果或网络资料。
每页先写读者任务、结论标题、关系与必需内容引用，再由智能体整理 brief，通过 build 调用 planContentSlide，实测后选择对象与构图。标题连读应形成叙事；标题不能只是“背景、方案、成果”。硬条件先筛选，风格在可用候选中选择。旧原样模板继续 layout+props；自主组合消费完整风格定义，原三套已适配风格同样可用。
媒体先于构图：照片用于场景证据，可裁切；界面截图、原始证据、含文字图必须完整 contain，不能因画面比例删除必要信息。记录图片来源与焦点。没有适合媒体则报告缺材料，不用蓝块或装饰图冒充照片。
每次局部改字只测量该框；结构调整只改变所属对象。人工几何、裁切、字体优先；覆盖无法迁移时给出冲突选项，不清空状态。所有预览与导出读取同一已保存 revision。
Kimi 提供方法与设计规范，智能体做内容与审美判断；确定性代码负责关系结构、几何、编辑、保存与导出，不宣称复制了官方自动排版引擎。

## 逐页内容决策（生成 brief 前必须完成）
- 列出重要事实及来源；数量区分 result（结果）、resource（投入）、method（合作方式）、context（背景）。保留单位、时期和口径，禁止把投入当产出、跨口径相加或把日期当指标。
- 重要数量用 metrics，item 写 nature、valueRef、labelRef；合作方式可以作为关键词并列，但必须标 method。次要数量留正文时，paragraph 写 dataDecision: {nature, presentation:"prose", reason}。生成器只提示漏标，不替代智能体理解业务；不得仅因出现数字就自动放大。
- 每段选择 semanticRole：主要说明 body/action，辅助说明 support/context，关键词 emphasis；有明确身份的短标签拆为 prefix。不得整页默认 body，也不得整句全部强调。
- 正文遵循用户指定字号，已验收八页项目 bodyPt:12，其他新稿按本次字号要求。指标/标题可更大，不能为填满页面放大正文。小标题与正文必须有字重/颜色区分。
- 新建证据页可使用 spacingPolicy:"balanced-evidence"，按剩余空间增加表格行高与模块间距。表格 data.verticalAlign:"middle" 使正文在行内垂直居中，横向仍按内容左/右对齐。短文字留白合法，不设整页70%硬门槛。
- 局部返工保留未点名页。已认可图片位置可用 layout row 的 widths（正数权重）锁住栏宽；不更换、裁切或拉伸图片来补排版。
