# 大师 PPT（dashiai-ppt）

大师 PPT 是一个由 @大师的AI小灶 持续维护的本地 PPT 生成与安全返工助手。你给它一个汇报目标、受众、页数和内容重点,它会从已接入的视觉页面中组合出一份可离线打开、可翻页、可编辑和可导出的演示;你明确指定旧稿时,也可以在保留主题和版式的前提下做最小差异修改。

公开增强版仓库：https://github.com/mujingquan835/dashiai-ppt-skill

当前版本: `0.4.1`

## 它适合做什么

- 行业研究、融资复盘、竞品分析和趋势报告
- 项目汇报、方案展示、路演材料和内部培训
- 需要快速形成结构完整、视觉统一、可继续编辑的演示文稿

## 你会得到什么

- 默认交付一份可编辑 PPTX,同时保留本地 HTML 预览源
- 预览页里可以继续改文字、换图片/视频、调整页面属性
- 字体编辑默认为全局模式，可按标题、正文和等宽文字统一替换；关闭全局开关后，可点击任意文字单独设置字体或输入本机字体名称
- 新生成的演示默认使用已内嵌的 OPPO Sans 4.0 作为标题和正文字体，可离线预览
- 可逐个调整图片槽的宽度、高度和形状（直角、圆角、圆形、胶囊、菱形），刷新页面后保留
- 你提供的图片/视频会写入本次 deck,成品不依赖原始素材路径
- 可以导出 HTML、PDF 或 PPTX
- 新导出的 PDF / PPTX 文件属性作者为 `@大师的AI小灶`
- 所有输出都保存在本机,适合继续归档、修改或交付

## 怎么使用

安装后,在 Codex/Agent 里说明要使用 `dashiai-ppt`,然后直接描述你想做的 PPT:

- 主题和目标
- 面向谁汇报
- 希望几页
- 想突出的结论或内容
- 偏好的视觉风格

新建 PPT 时,Skill 会从 12 套风格中智能匹配最适合本次内容的 9 套,生成一张 3×3 九宫格并列出 1-9 的选择理由;你选定后才开始生成。明确指定已有 PPT 只改文案或数据时沿用原风格,不会重复打断你选主题。

## 增强版工作方式

- 说“做一份 / 新建 / 再做一个 PPT”且未指定旧稿时,始终新建独立目录和独立成品,不会误用历史 PPT。
- 只有明确指定旧稿、页面或 `goal.json` 时才进入返工;每次写回前自动保存快照和变更报告,未授权的换主题、改页数、换版式会被拦截。
- 新建与返工严格分流，历史成品不会被当作新任务的默认输入。
- 用户指定结构、格式或输出路径时，始终以本次要求为准。

## 安装说明

推荐从 GitHub 一键安装：

```bash
npx skills add https://github.com/mujingquan835/dashiai-ppt-skill --skill dashiai-ppt
```

也可以把整个 `dashiai-ppt` 目录手动放到本机 Skill 目录中，然后重新打开会话。

本机需要能运行 Node.js 20+ 和 npm。首次生成时依赖会自动准备。
