# Dawang-PPT 汇报版式预览版

版本：`v0.2.0-preview.20261104`，预发布。在 `v0.2.0-preview.20261027.1` 的完整规则基础上，合入此后的排版、复核与内容大纲改进。规则锁定版本与资料指纹与 `.1` 相同，新增的只是按章节整理的规则清单；编辑器只为“同一图片只存一份”调整了读取方式，保存与导出流程未改变，默认仍交付一个可离线编辑的 HTML。

## 定位

专门面向中文工作汇报、述职、复盘和季度/年度总结。新增的检查和页型都围绕汇报读者需要看到的内容：整体结论、成果数据、问题差距、下一步。

## 主要变化

**先整理大纲，缺口只问一次。** 新建稿件先把材料整理成 `outline.json`，`outline:check` 列出缺口（缺什么、为什么需要、缺了会怎样）并建议每页页型。默认只检查用户要做的那几页（`scope: part`）；用户明确要完整汇报时才检查整稿结构。缺材料由用户决定补充还是按现有材料生成，同一份材料不反复追问。

**排版工具与页型，不再手算坐标。** 网格、指标组、流程、编号列表、图片网格与表格由工具保证对齐与成组；几何检查会指出同行图片不等高、数字与单位分离、近似对齐和小图放大。每页写分区 `zones`，可先看线框再生成。

**数据优先于图片。** 多个数字默认放进圆角数字色块（标签在上、数字在下，重点项加强调色竖条，空余时自动补图标）；照片铺满整栏、轻度裁切；“色块＋照片渐隐”拼板只用于文字少、几乎无数据的页面。

**汇报版式逻辑与九组配色。** 从一套 245 页工作汇报模板蒸馏出排版逻辑（只取方法，不含其图片、文案与品牌）：一深一浅一跳的颜色职责、锚定块、同列对应、镜像对照、时期色带。新增页型 `targetVsActual`（目标对实际）、`contrastColumns`（亮点 vs 待改进、问题 vs 改进）、`periodColumns`（按季度/阶段分栏）、指标带 `kpiStrip`、带章节标签的页头，以及九组汇报配色。详见 `references/fusion/report-layout-logic.md`。

**复核更具体，同一轮内修完。** 新稿必须记录每页重点与视觉决定，并按章节写规则清单。独立复核除规则外还看对齐、主次和图片三条视觉标准，fail 会写出页码和具体问题；有 fail 时在同一轮内重新构图并复核，最多三轮。可选复核者的思考档位。用户确认过的数字色块、深色侧栏、照片拼板等版式优先于“禁止卡片”类条款，复核不会因此要求去掉。

**离线 HTML 更小。** 同一张图片在离线 HTML 中只存一份。

## 下载与前置条件

下载 `dawang-ppt-v0.2.0-preview.20261104.zip` 与可选的 SHA256SUMS.txt。**完整规则资料需单独合法取得并配置**；公开包不附未获再分发许可的原文。没有资料不能按完整能力新建稿件。安装和配置见 [使用说明](USAGE.md)。可编辑示例 HTML 与上一版相同，重新附在本页方便下载。

## 验证

发布前全量回归 261 项：260 项在同一次运行中通过；1 项浏览器用例（四种外观的编辑、保存与导出）在机器满载时超过 180 秒时限，单独重跑 20 秒内通过。打包检查（公开入口文件的命名与私有路径）通过。实际 ZIP 解压后独立安装依赖：未配置规则资料时 `doctor` 显示未就绪；配置同版完整资料后显示就绪，并用包内合成示例实际生成页面截图查看。

主要环境为 macOS、Node.js 24 和 Chrome。跨平台、各客户端实际加载、真实稿件视觉效果与 Office 兼容仍需分别验收；程序检查通过不等于模型成稿必然好看。
