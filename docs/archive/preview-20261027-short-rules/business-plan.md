# 商业提案与产品介绍

先明确谁面临什么具体问题、方案让谁如何完成关键动作，以及这对受众有什么意义。价值主张应有功能、机制或案例支撑；不要用抽象形容词替代产品能力，也不为形成销售故事补造市场规模、客户成果或收入。

从材料选择需求、方案、核心操作、证据与实施边界。与其他方案比较时只比较可核对的维度，不凭空贬低其他产品。商业预测、已实现收入、试点反馈及未来计划分别呈现，不能互相替代。

产品截图较多时，可评估沿用真实界面的底色、强调色与文字色；投影可读性和用户品牌规范优先。关键操作应在正文可直接读到，截图承担展示或证据作用，不让读者在小字图中寻找全部价值。提出的下一步应符合本次受众能做的决定。
