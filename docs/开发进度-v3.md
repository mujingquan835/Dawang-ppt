## M0 已实施

1. `8ea13b9` 保存既有导出修复：背景装饰 SVG 与兼容预览、实际字体识别和字体包、伪元素、可见文字宽度、合法圆形与连接线。原编辑界面不换用其他基座。48 项回归通过。SVG 仅用于背景装饰，核心对象继续可编辑。
2. 从 Grok 快照 `23b15a1` 按功能整合：语义角色、月白令牌、材料分析、图片尺寸探测、横竖混排、场景识别、设计 lint 基础、导出后 ZIP/OPC 校验。导出校验检查实际写到磁盘的文件，同时写报告。
3. 风格选择已改为外观选择元数据：撤出 Kimi 自主设计格与三路线选择，目标统一指向 content-first。尚未完成迁移的预设不能冒充可用模板。当前 CLI 默认入口会在 M2 接入，不能据此宣称所有新稿已走新引擎。
4. Kimi 参考读取为外部本机路径；缺少场景文档、缺少预设目录均明确返回不可用/空结果。公开源码不复制 Kimi 原文，不合入携带原文的分支历史。
5. 用户确认保留原 theme17 外观，因此未整合其旧模板 flex/字号/页脚改版及生成 bundle。参考分支工作区保持原样。
