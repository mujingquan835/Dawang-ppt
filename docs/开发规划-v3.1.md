# Dawang-PPT 开发规划 v3.1（精简版）

> 日期：2026-10-16｜状态：计划｜取代 v3 的里程碑安排（v3 的原则、数据与编辑契约继续有效）。
> 仓库 `docs/开发规划-v3.md` 是 v3 的副本，Codex 下次提交时改为本文件。

## 1. 目标与不做什么

**一句话目标：** 用新主线（先分析内容，再自动排文字和图片，可编辑、可导出）把桌面《一人多线市场汇报_8页大纲_定稿版》做成你认可“可用”的八页稿，并让日常使用默认走这条主线。

| 不做 | 说明 |
|---|---|
| 新增风格、皮肤、合成展示稿 | 只为真实稿补能力 |
| Kimi 风格入口 | Kimi 只作为排版规则和检查，不作为可选风格 |
| 改原 17 主题模板源码、原编辑器 | theme17 保持原外观 |
| 全量迁移 1091 个模板页 | 只改写真实稿用得上的 2–3 页 |
| 原生表格/图表/SmartArt | 用可编辑文字、形状、线条 |
| WPS 验收 | 已取消；用 PowerPoint 实测 |
| Kimi 原文进仓库 | 继续从本机路径读取 |

## 3. 只剩 3 步

### S1 八页真实稿（必须）

| 内容 | 说明 |
|---|---|
| 多区域排版 | 一页可放多个对象（文字、表格、流程、图片组、图表）；区域大小按实测内容分配。先做第 1、6、8 页 |
| 去掉等分 | 文字条目、栏宽不再平均分；短文字按实际高度排布，允许留白 |
| 图片 | 按真实横竖比例排；不拉伸；不裁掉主体；文字不压主体；缺图显示占位并列清单，不编造 |
| dashi 好版式 | 从 theme14 高频页（page001/007/010）改写 2–3 个为版式预设，八页中至少实际用上 1 次 |
| 风格 | 按大纲视觉规范：白底、深蓝 #16283C、铜橙 #C0652B |

**验收（你能看到的）：**
- 八页在原编辑器中完整显示；改字、换图、拖动、撤销、保存后重开都正常。
- 导出 PPTX，PowerPoint 打开无修复提示，文字可编辑，版面与预览一致。
- 对照大纲：数据、照片一项不少，没有编造；正文 12pt（按用户 2026-10-16 新决定；标题与重点层级另设）；无溢出。
- 表格、图表、流程图区域填充 ≥70%；短文字不强求。
- 每页截图＋一句“为什么这样排”，**你说“可用”才算完成**。

**估计：** 3–5 天。

### S2 收尾：让日常使用走新主线（必须）

| 内容 | 说明 |
|---|---|
| Kimi 三个家族降级 | 改为外观（配色字体）＋排版规则，不再作为独立风格入口 |
| 清理 | 删除不再使用的旧分支代码、页型硬编码；测试全部通过 |
| 更新 SKILL.md | 正常流程：大纲 → 九宫格只选外观 → 新主线出稿 → 原编辑器调整 → 导出 |

**验收：** 拿一份新大纲（你给或沿用八页稿内容）按 SKILL.md 正常跑一遍：没有 Kimi 风格选项；出稿走新主线；PowerPoint 打开正常；你确认流程顺手。
**估计：** 1–2 天。

### S3 第二份真实稿（可选）

只在你提供周报或激励稿材料后进行，验收同 S1。**估计：** 1–2 天。

## 4. 节奏规则

| 规则 | 说明 |
|---|---|
| 小步提交 | 每完成 2 页提交一次，并给你截图 |
| 卡住就停 | 同一问题修 3 轮仍不过，停下给你选项 |
| 不扩范围 | 不在本表内的需求先问你 |
| 汇报格式 | 计划 / 本地实现 / 测试通过 / 实测（PowerPoint）四栏，不夸大 |

## 5. 与 v3 的区别

| v3 | v3.1 |
|---|---|
| M0–M6 七个里程碑，先工程后真实稿 | 只剩 S1–S3，**真实稿优先**，能力按需补 |
| M1/M2/M4 作为独立门槛 | 已完成部分直接沿用；未完成部分并入 S1 |
| M5/M6 预设与批量扩充 | 只改写 2–3 个 theme14 页；批量扩充暂不计划 |
| 三份真实稿、PowerPoint+WPS | 八页稿一份必须；其余可选；仅 PowerPoint |
| 内容区填充 ≥70% | 只用于表格、图表、流程图区域 |
