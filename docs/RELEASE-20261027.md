# Dawang-PPT 同事分享版

版本：`v0.2.0-preview.20261027`。这是预发布分享版，运行时代码包仍为 0.2.0-dev，不冒充稳定版 0.2.0。

## 本次变化

- 制作规则随包提供：7 类场景，完整制作流程、内容策划、主动文案编辑、媒体取舍与视觉复核。
- doctor、rules:read 和 prepare 默认使用内置 Dawang-PPT 规则；缺失或指纹不符会报告失败，不依赖其他演示 skill。
- 新建工程使用 Dawang-PPT 制作标识；旧版已保存工程继续兼容，保留人工编辑。
- 离线 HTML 顶部保存与状态、原文件关联写入、撤销重做、画布拖动与文字双击编辑。
- 纳入最新素材证据用途、关键区域、产品视觉语言和机制对应实例的制作提示。
- 独立 ZIP 仅分发当前 skill、运行资源、说明和许可，仓库旧文件继续保留。

## 下载与使用

下载附件 `dawang-ppt-v0.2.0-preview.20261027.zip` 和可选的 `SHA256SUMS.txt`。独立包与 GitHub 自动生成的 Source code 不同；分享给同事时推荐独立包。

详细步骤见 [使用说明](USAGE.md)。成稿默认一个可离线编辑 HTML，PPTX、PDF、图片按需导出。

发布前完整回归：198 项通过，0 失败。补充的独立规则、指纹漂移和新版对比度专项共 7 项通过，0 失败。覆盖当前源码与原有兼容路径的制作、编辑、撤销重做、裁切、保存重开、离线文件和导出检查。

规则隔离验证覆盖没有外部规则安装时的 doctor、全部 7 个场景读取、prepare，以及新旧制作标识兼容。另检查内置规则修改后会阻断，维护者显式审核更新指纹后才恢复。

从实际 ZIP 解压后独立安装依赖，在隔离 HOME 与无外部规则环境中验证：注册、doctor、prepare、HTML 制作、patch/publish、真实 PPTX/PDF 导出全部通过；生成合成页截图并实际看图。包中无 node_modules、个人绝对路径、旧规则读取器和历史规则锁。校验覆盖 ZIP CRC 及清单中每个文件的 SHA-256。

主要验证环境为 macOS、Node.js 25、Chrome。跨平台、各客户端新会话加载、真实业务材料视觉质量及目标 Office / WPS 打开效果需分别验证。PPTX 字体未嵌入；PDF 为截图型。
