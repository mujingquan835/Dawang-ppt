# GitHub 图文介绍设计

用户已确认完整方案：README 图文首页、4页可编辑合成案例、真实操作图解。目标是让首次访问者看懂用途、效果、安装前置条件和第一步操作。

采用现有 Dawang-PPT 引擎生成公开合成案例与真实界面截图；纯静态海报难以证明可编辑性，只有文字与命令不利于首次使用，因此选择“实际成稿 + 实际编辑器 + 可下载HTML”。制作规则、引擎、既有许可和资料前置条件保持不变。

首页顺序：成稿预览 → 产品定位与适用场景 → 方法与示例 → 编辑保存图解 → 直接试用/安装制作两条路径 → 事实和格式边界。详细使用说明增加图文索引。案例主题为跨团队交接试点，4种版面展示封面、数量比较、带分支流程与行动时间线，数字及业务内容全部标注合成。

公开资产不得带个人路径、规则原文或真实业务素材。可复用的材料、authored源文件、截图脚本与生成说明一起维护。截图必须来自当前引擎，说明插图不得冒充软件界面；HTML须离线可编辑，并验证修改与重开。现有预发布安装包保持不可变，示例另行提供下载并关联到GitHub说明。
