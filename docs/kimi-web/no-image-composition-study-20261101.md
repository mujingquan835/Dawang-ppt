# 无图输入、图片组织与少字排版：本地参照研究

2026-11-01。用户要求继续理顺候选skill，参照dashi-ppt和PPT-master。本轮先做规则与成图研究，不改候选制作规则、不切换日常安装。研究的是本机现有版本，不代表线上最新版本。

## 结论

三者是可叠加的判断维度：无图输入决定素材取得与替代表达；图片组织决定已选视觉与正文的关系；少字排版决定当前阅读场景下的表达密度与视觉重心。保持单一制作主流程，在原逐页提纲中完成这些判断，按触发条件读相应方法。

## dashi的规则与页面

来源：本机dashiai-ppt的SKILL.md、references/design-composition.md；实际查看此前保留的theme11_page007、010、023原始渲染截图。这些默认文案仅作页面研究。

- 先盘点素材的分辨率、比例和主体，再选择有真实媒体槽、容量适合的layout；图文关系与信息角色影响选页。
- 没有素材时可以选择无图版式，不能用图标代替必需业务图片。全文可读性不足时换布局，不能无限缩字。
- page010以展示字体、关键词强调、短句断行和留白建立主视觉；page007以窄主张区和宽条目区分配面积；page023以主张、步骤链、解释层组织阅读。
- 已登记模板和字段契约有助于稳定落地，但不应迁入我们自主设计流程。其默认内容图片单次使用限制也不适合直接继承：同图总览与局部可以承担不同任务。

## PPT-master的规则与页面

来源：本机skills/ppt-master/SKILL.md（metadata 4.3.0），references/strategist.md §h、§4、§6.1，strategist-image.md，image-layout-patterns.md，image-layout-spec.md。归属检查脚本返回0。此次是研究其实现，不调用其新建PPTX流程。

- 来源区分none、provided、ai、web、placeholder；none可由原生图表、关系图完成视觉表达，允许的图片来源不等于每页图片配额。
- 图文词汇按页面骨架、修饰、需要预处理素材的效果、跨页连续关系分层；按具体表达任务选取，目录不是覆盖清单。
- 区分直接标注原图与另设同源放大图；后者保留选区对应。准确文字、数值与说明保持原生可编辑。
- 比例根据实际图片尺寸计算，contain空余过大就重组区域，不拉伸填满；等权分格只适合语义上并列的图片。
- 阅读型、业务平衡型、讲述型有不同的信息承载方式；少字取决于用途，不能只改字号或删成碎片。没有备注时也必须保留必要解释。

实际将examples/ppt169_image_text_showcase/svg_final中的03左图右文、14褪色底图大字、16中心放射标注、20黑板收场用浏览器渲染并逐页查看。它们分别展示图片辅助叙述、图退为肌理、围绕对象解释和单句收束；这组是风格展示样本，不能将每页不同配色或某页大幅留白直接设为普通整稿规则。仅研究可读性与关系，未验收其PPTX导出。

## 拟融入候选指南的结构

| 何时需要 | 判断内容 | 可采用的方法 |
|---|---|---|
| 用户未给图片 | 是否真的需要图片；缺的是证据、解释还是氛围 | 已授权素材；可编辑关系示意；按授权补图；文字主视觉；确需用户后补时说明缺口 |
| 已选图片参与表达 | 图片是主角、辅助、证据、操作对象还是底图；实际比例与必保留区 | 不对称图文、上下关系、图上标注、总览与局部、同口径并列、多图主次 |
| 页面文字少或用于现场讲述 | 完整意思是否成立；主视觉和支持层在哪里 | 观点主导、对象主导、关系主导；字体对比、关键词、行长、留白和主题图形配合 |

图片角色可组合，方法目录保持开放。补图不自动触发网络或付费生成；图库不适合当前事实时回到内容自主设计；少字不作为删除条件或堆装饰的理由。无需新增工程字段或另一套用户确认流程。

## 后续验证建议

沿用相同短文案，分别测试无图纯文字、无图关系示意、有图主视觉、完整图与局部、真实并列组图；按用途检验阅读密度。每个样例只覆盖对应方法，不为了展示目录把方法全部塞到一份稿。先看真实效果，再决定最小规则调整；这轮研究不等于新方法均已验收。
