## 使用

- 图片、图形与文字：单击选中，按住鼠标左键直接拖动，拖动中实时预览；松手提交一次修改，撤销恢复拖动前位置。拖动中按 Escape 取消。（2026-10-27 起，用户确认：文字也单击即拖动，不再需要“移动”按钮或 Alt。）
- 编辑文字：双击文字进入编辑，光标落在双击处。Escape 先退出编辑并保留选中，再按一次取消选中；点击页面空白处也取消选中。
- 位置与大小：右侧不显示 X、Y、宽度、高度或图片焦点数值（用户明确决定，不得加回）。通过画布拖动与选框八个缩放手柄操作，按住 Shift 等比缩放；拖动时吸附页面边缘、中线与其他元素并显示对齐线，按住 Alt 关闭吸附；选中后方向键微调 1px，Shift+方向键 10px，连续微调合并为一步撤销。组内对象通过“整组/子对象”选择范围。内部仍保存1920×1080逻辑画布坐标，保证保存与导出一致。
- 撤销与重做：在顶部工具栏（⌘Z / ⇧⌘Z，Windows 为 Ctrl+Z / Ctrl+Y），不再出现在每个元素的属性面板中。
- 图片裁切：在“图片展示”中选“裁切…”，或点击“裁切图片”。拖动八个边框手柄选择区域，拖动框内图片调整展示位置，可点击放大/缩小。确认后生效，取消不改工程。原图保留，裁切可撤销、重做和再次调整。保存或导出会确认当前裁切。
- 文字：右侧“文字属性”集中设置字体、字号、颜色与对齐。字号单位为 pt，内部保留 CSS px=pt×2 的导出契约。选择本机字体不代表该字体已安装或会嵌入导出文件。
- 修改当前文字的字体会切换为单独字体模式；“全稿字体”默认折叠，可展开统一修改标题、正文和等宽字体。旧模板仍保留原单独文字字体入口。
- 富文本：整体颜色、字号、字体应用到所有分段，保留内容和字重。多色文字显示提示；“分段文字与样式”可展开分别编辑，不必先清除富文本。
- 图层：默认折叠，展开后可置前或置后；同一次选择刷新时保留展开状态。
- 页面底部仅保留原 GitHub 链接与 Jingquan 名称。
