# 文案编辑迁移演练材料

用于检查内容规则是否可用于不同材料，所有业务内容和数字均为合成测试材料，不代表实际客户或项目结果。执行时读取当前技能及文案编辑指南，只提供原材料、受众和范围，先生成表达，再检查约束。不要把评判点当作固定措辞模板。

本轮为同一制作模型的文案演练；后续独立评估时不要提供本轮答案。文件保留原材料与行为约束，避免把特定答案写入技能。

## 1. 没有现成金句的产品材料

- 任务：面向首次使用者制作一页产品功能介绍，允许优化文案。
- 原材料：工具支持多份文档依次转换。处理结束后生成汇总清单。失败的文件在清单中列出失败原因。
- 检查：从材料提炼使用价值，说明批量处理与结果集中查看；不虚构时间节省、并行处理、自动修复或成功率。

## 2. 有进展也有缺口的工作汇报

- 任务：给负责人汇报活动执行状态。
- 原材料：本月计划10场活动，已完成8场；另2场因场地延期。到场人数尚未统计。
- 检查：突出完成状态和阻碍，保留待统计状态；不声称活动效果提升，不把场次当人数，不添加未经提供的补办承诺。

## 3. 同一事实，不同受众

- 任务：分别给普通使用者和技术评审写一个标题及一句说明。
- 原材料：任务超时后标记为失败，页面显示超时原因。用户可以点击重试。当前没有自动重试。
- 检查：使用者表达应易于操作；技术表达保留状态和重试边界；两版事实一致，不承诺自动恢复或问题必然解决。

## 4. 培训材料中的条件与操作

- 任务：把说明整理成一页操作培训内容。
- 原材料：先导入名单，再确认导入字段与系统字段的对应关系。发现重复记录时选择保留或合并。确认后写入系统。
- 检查：动作顺序与确认条件明确；不能删除重复记录的选择环节，不把手动确认说成自动识别处理。

## 5. 已锁定的文案

- 任务：只调整版面，文字逐字保留。
- 原材料：本月计划完成测试，下月是否上线另行评审。
- 检查：原句保持完全一致；不能因标题更有吸引力而改成“下月上线”。

## 6. 已经清晰的原句

- 任务：制作使用引导页，可以优化表达。
- 原材料：先看原片与成片对比，再决定是否导出。
- 检查：允许保留已有好句；不为证明进行了改写而改成夸张的效果保证，不额外增加必需步骤。

## 7. 尚未发布的产品

- 任务：面向潜在试用者介绍产品进展，可以优化表达。
- 原材料：预计下月启动Mac版小范围试用；Windows版尚未排期。
- 检查：时间为预计、范围为小范围试用、平台限定仍可见；不写成全面上线或跨平台可用。

## 评判方式

先看是否遵守事实和任务范围，再看主张、具体性、受众适配及可操作性是否改善；不设金句数量、长度或标准答案。记录实际输出、保留项、改写依据和未验证部分。文字演练只验证编辑判断，不替代实际页面、不同模型执行或用户效果评价。
