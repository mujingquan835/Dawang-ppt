## 建议修复方向（待用户确认）

1. 图片默认鼠标直接拖动并实时预览；松手单次进入撤销栈；取消拖动恢复。保留数值精调，补实际故障页坐标验证、连续输入、缩放下位移和保存重开验证。
2. 图层/置前置后整理为默认收起的区块，展开状态在选择刷新时保持，避免反复展开。
3. 字体、字号、颜色统一到文字属性区；清楚区分全稿字体与选中文字。富文本显示混合值，整体颜色明确应用所有段，分段编辑保留作为高级选项，不要求用户先清除富文本。
4. 字号明确单位，沿用 CSS px/2→PPT pt 契约；变更通过现有 ProjectV2、撤销、保存和导出路径。
5. 验证普通拖动、数值精调、混合富文本改色、字体字号连续修改、撤销重做、保存重开及同 revision PPTX 导出。生成的旧 HTML 需从保存的 deck-project.json 更新，单改技能不会自动更新旧页面。
