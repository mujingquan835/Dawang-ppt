## 1. 决策摘要

保留材料理解、自主设计、完整规则、可编辑网页工作台和单 HTML 交付。重构的是材料与页面之间的交接：材料里的对象、事实和关系必须进入设计；设计必须说明主要区域如何帮助读者理解；验证必须检查最终呈现是否保住这些关系。

采用“内容模型 → 页面设计 → 可编辑元素”的渐进改造，不重写渲染器，不建设独立的第二套工程状态，不强迫每页套用固定组件。主题负责视觉语言，页面构图由内容和用途决定。

本轮只新增方案文档。未修改运行代码、技能规则、安装链接、用户成稿或工程；未创建开发分支、提交或发布。

- [新流程与内部契约](authoring-system-v2/contracts.md)：字段、状态、设计自由度、兼容和返工。

## 2. 成功与非目标

### 成功标准

1. 必需事实与核心关系有来源、有去向、有可见表达；遗漏和主动删减可区分。
2. 页面有明确阅读任务，关键区域的设计与信息关系相符；不以组件数量、装饰数量评价质量。
3. 长名称、缺照片、数据变化或换主题后能重新评估容量，发现无法满足约束时明确退回设计。
4. 事实、关系与渲染缺陷不因复核次数耗尽自动变成通过；审美意见单独呈现。
5. 旧稿可编辑、保存和重开；既有人工位置与裁切不被自动布局覆盖。
6. 实际样稿经用户确认后才能认定效果验收，程序通过不代表视觉满意。

### 不做什么

- 不自动生成缺失业务事实或擅自补造照片；不默认联网补素材。
- 不强制“有时间必须画箭头”“有数据必须用某一种卡片”。
- 不把所有任务都定义成工作汇报，不要求所有提案包含复盘章节。
- 不扩张到 PPTX/PDF 新能力；按需导出和单 HTML 默认交付保持。
- 不全量重做已有演示工程；不把私有业务样本加入公开仓库。

## 3. 新制作链路

| 阶段 | AI 的责任 | 程序的责任 | 进入下一阶段的条件 |
|---|---|---|---|
| 理解材料 | 完整阅读，识别事实、关系、来源、缺口和用途 | 提取材料、管理媒体、校验引用 | 必需信息有记录；不确定项有标识 |
| 规划页面 | 确定阅读任务、重点、页序与内容取舍 | 检查内容去向与页面约束 | 每个必需内容有页面或明确处理理由 |
| 选择表达 | 对主要区域选择合适表达，分配面积、决定图片用途 | 校验区域与引用、提供组件能力信息 | 核心关系有表达方案，容量初步可行 |
| 排版生成 | 写上屏文案、组合工具、设计自由元素、逐页看图 | 测量、排列、渲染、保存元素与引用 | 内容与渲染检查通过；设计声明对应实际元素 |
| 独立复核 | 判断最终页面能否完成阅读任务 | 提供材料摘录、关系、截图、验证记录 | 无未解决阻断；审美意见单独标明 |
| 发布与维护 | 如实说明版本状态、开放意见、用户决定 | 原子写入 HTML、保留修订与回退 | 复核对应当前内容、主题与页面版本 |

这些是同一轮内部步骤，不是每一步都让用户确认。只在信息缺失需要业务决定、页数/配色确实待定、已有授权范围不足时合并提问。默认先推进不依赖回答的工作。

## 4. 规则的重新分工

规则不再重复承担设计、程序检查与发布状态三种职责。

- `SKILL.md`：保留入口流程、优先级、必要阅读、交付和提问边界，链接细则。
- 完整制作规则：继续锁定读取，不删减、不用本方案替代；适用性和用户例外仍需记录。
- 内容契约：事实、关系、引用、必需项与缺口处理。
- 设计指南：表达选择和案例解释，允许多种合格设计。
- 组件契约：输入、输出、容量和缺素材状态，负责几何可靠性。
- 验收规范：按内容/渲染/设计分类；通过、阻断、审美意见分别记录。

旧规则处理详见审计表。重点替换“每页至少一个组件”的代理指标；不新增“每页至少几个图形”的替代指标。规则清单仍可按章节组织，但检查结果必须能落到页面与区域，不能只给整稿一个模糊结论。

### 每个工作包的交付要求

1. 说明具体行为变化和兼容影响。
2. 运行与改动相关的现有检查及新增验收案例；只有依赖变化或失败时扩大检查。
3. 涉及页面效果，提交候选截图、关键内容映射和失败修正记录；真实业务资料仅本机保存。
4. 不宣称未运行的测试或用户效果验收通过。

### 样稿制作顺序

先完成一个“缺照片的人物与排期混合页”及一个“条件分支流程页”，验证内容→设计→元素→复核能跑通；然后制作完整活动方案与四页合成试点稿。小闭环防止开发到最后才发现数据契约不能表达真实页面。

## 6. 兼容、安装与回退

- 沿用 `ProjectV2` 作为唯一工程真相；新内容/设计契约用显式版本字段启用，旧字段继续读取。
- 新规则只约束启用新契约的工程。旧稿不自动补造关系或标成新版验收通过。
- 旧稿局部编辑保持 ID、人工覆盖和历史；升级需显式操作，保存原文件，展示内容映射差异。
- 主题变化使相关布局、对比度与视觉复核失效；不代表允许覆写手工锁定几何。
- 代码开发在隔离分支或工作树进行；日常安装保持现状，直到第 6 步获用户确认。
- 安装回执记录提交、规则指纹、快照路径和入口；回退恢复旧链接，保留新版候选工程，不能强行用旧运行时覆写未知新字段。
