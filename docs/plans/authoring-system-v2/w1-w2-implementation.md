## 当前边界

1. 本次交付的是内容/设计底层契约及接入，不是已经完成的新制作技能，不重做用户现有成稿。
2. 页面绑定检查基础可见性和区域几何，不能单独检测所有 CSS 遮挡、字形裁切或表达含混；现有浏览器测量继续执行，增强能力在 W3/W4。
3. 同一关系的成员与边/行当前在一个区域内完整绑定；跨区域拆解需显式子关系，不隐式拼接证据。
4. W4 的依赖失效缓存和分级发布尚未实现：原来的三轮放行与 fail 项复核策略仍在，因此不将候选版作为正式质量闭环启用。
5. 绑定内容人工改字后需要核对；普通编辑命令支持撤销/重做状态恢复，浏览器原生文字撤销可能保守地仍标为待核对。
6. 清除待核对状态暂由维护流程使用 saveProject/expectedRevision，在核对模型和绑定后进行；本次未新增面向用户的确认按钮或工作流。
7. 缺口 placeholder 是记录状态，不是伪造用户授权；缺口提问仍沿用既有技能规则。
