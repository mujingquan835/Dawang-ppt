## 4. 保留、完善、替换和不采用

| 现有机制 | 决定 | 理由及实施边界 |
|---|---|---|
| 完整规则读取与指纹 | 保留 | 不用新的短摘要替代原文；减少的是重复操作，不是设计要求 |
| authored 自由元素与 ProjectV2 | 保留 | 承载可编辑自主设计，不能退化成固定模板填空 |
| 网格、表格、图片、流程工具 | 保留并完善 | 输入容量、成组关系与状态完善，比新增重复工具优先 |
| contentPlan.nodes / requiredContentRefs | 扩展 | 当前已存在引用链，新模型接在这条链上 |
| 配色确认与缺口一次合并询问 | 保留 | 用户明确要求优先；不新增逐页审批 |
| 章节规则清单 | 完善 | 保留章节结构，判定细化到页面区域与证据 |
| 每页至少一个认可组件 | 替换 | 容易成为达标捷径；改为关键关系可见表达 |
| 按 fail 条目继承旧 pass | 替换 | 改为按依赖指纹复用未受影响判断 |
| 三轮后所有意见放行 | 替换 | 预算控制仍保留；正确性缺陷继续阻断，输出待确认稿 |
| 强制每页图表、色块、装饰数量 | 不采用 | 纯文字观点页也可成立，不能为过关制造视觉噪声 |
| 主题固定对应版式 | 不采用 | 主题不拥有事实和关系，完整模板适配仍由 AI 判断 |
| 整稿覆盖重建以便返工 | 不采用 | 继续沿用 patch、稳定 ID、人工覆盖和修订检查 |
