## 可复现证据

`npm run examples` 生成 output/matrix；`node examples/verify-matrix.mjs` 导出及独立渲染复核。`node examples/legacy.mjs` 生成两个旧样例；运行原技能export:pptx后用 `node runtime/verify-pptx.mjs <PPTX>` 复核。旧运行时需要在其project目录执行npm ci。

逐页PNG、overview、输入台账、render-plan、qa/report、export-report、independent-report保存于本地output；不把用户稿或大生成物提交公开Git。

## 已知差异与未完成项

- LibreOffice的宋体标题存在字体回退差异，浏览器与PPTX不能承诺像素一致；新版本需要明确字体映射和目标客户端校准。
- 五项视觉评审尚未全部达到并证明≥4分；当前简洁构图证明机制，不代表已经复现完整源设计的美学密度。
- 旧导出报告出现2/5项警告，仍需逐对象复核；旧装饰轮廓字的预期超边界已作为装饰声明，不作为正文漏检。
- 旧主题媒体/全部编辑回流未统一，原版主题容量依旧受原契约限制。
- 当前编辑提供文字、图片、字号与位置，不含完整数据表格的浏览器编辑面板；原生表可在Office中编辑，但该客户端实操仍待验收。
- 自动参考图迁移、用户PPTX模板解析、其余风格适配和七类场景未完成，按P5独立推进。
- 排版仍为固定区域与受控参数，尚需智能体依据测量有限修正；不声称全自动审美引擎。
