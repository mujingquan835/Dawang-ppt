## Global Constraints

- 统一展示名Dawang-PPT、技能dawang-ppt、现有公开仓库Dawang-ppt；原全局两个技能及用户稿保持可恢复。
- 编辑方式为“结构化＋局部自由”；SmartArt为可编辑关系图；PPTX仅要求文字与图形可编辑，不要求原生表格/数据图表。
- 全部60份源资料都有迁移去向；模板可按适用范围使用不同构图，不建设所有风格×所有对象的虚假兼容矩阵。
- 新HTML画布采用原1920×1080；PPTD规格960×540的几何和字号乘2；PPTX为13⅓×7½英寸，逻辑坐标/144为英寸，CSS逻辑字号/2为点值。实际客户端回归验证该换算与字体测量。
- 原业务事实、图片、表格行列和关系不可为布局删减；未确认许可的资料/字体/图片及原专有导出器不进入新公开分发包。
- 发布前依次完成内容、几何、逐页视觉、编辑、导出和用户效果评审；同一问题最多三轮自动修正。

1. 旧HTML已改过字体、图片、复制/排序页面：导入/重渲染必须保留最终状态，而不是重新读取最初goal覆盖修改（Task 1/2）。

## 公共接口与类型

```ts
type ProjectV2 = {
  version: 2;
  requirements: Requirements;
  sources: SourceLedger;
  media: MediaLedger;
  contentPlan: ContentPlan;
  designChoice: DesignChoice;
  slides: Array<TemplateSlide | CompositionSlide>;
  editorState: EditorStateV2;
  revision: string;
};

type TemplateSlide = { slideId: string; mode: 'template'; layout: string; props: object; contentBindings: object; mediaBindings: object };
type CompositionSlide = { slideId: string; mode: 'composition'; styleId: string; compositionId: string; objects: SemanticObject[]; elements: SceneElement[] };
type SceneElement = { id: string; parentId?: string; type: 'text'|'shape'|'line'|'image'|'icon'; bounds: [number,number,number,number]; style: object; contentRef?: string; mediaRef?: string };
type SemanticObject = { objectId: string; kind: string; data: object; nodeIds: string[]; relationships: object[]; bounds: [number,number,number,number]; overrides: object };
type EditorStateV2 = { slideOrder: string[]; skippedSlides: string[]; deletedSlides: string[]; overrides: object; history: object[] };
```

Requirements/SourceLedger/MediaLedger/ContentPlan/DesignChoice按规格定义JSON Schema：ContentPlan至少含受众、用途、主场景、逐页readerTask/relation/必需内容引用；DesignChoice含styleId、sourceVariant和原样模板约束。SourceLedger区分原资料和用户编辑。图表/表格数据保存在SemanticObject.data，不以每个绘制形状的数据为第二真相。

模块接口固定为：

```ts
importGoal(goal: object, embeddedState: object | null): ProjectV2;
loadProject(projectFile: string): ProjectV2;
saveProject(projectFile: string, project: ProjectV2, expectedRevision: string): SaveResult;
resolveStyle(styleId: string, sourceVariant?: string): StyleDefinition;
planSlide(contentSlide: ContentSlide, style: StyleDefinition, capabilities: CapabilityRegistry): PlanningResult;
layoutObject(object: SemanticObject, style: StyleDefinition): SceneElement[];
applyEditCommand(project: ProjectV2, command: EditCommand): EditResult;
renderProject(project: ProjectV2, outFile: string): BuildManifest;
collectExportObjects(page: BrowserPage, project: ProjectV2): ExportObject[];
exportEditablePptx(objects: ExportObject[], target: ExportTarget): ExportReport;
measureProject(url: string, project: ProjectV2): QaReport;
```

- SaveResult/EditResult包含ok、project/revision或issues/conflicts；冲突时不部分写入。
- StyleDefinition包含视觉、构图、素材/图表语言、密度、页型、能力及来源状态；不只是颜色tokens。LegacyStyleDefinition使用同一结构，并记录原主题与原组件样本。
- PlanningResult明确所选模板/构图、原因、内容绑定及未满足项；无可行结构则返回冲突，不制造空页。
- ExportObject以text/image/shape/line为核心，保留slideId/elementId/sourceRef及是否装饰位图；导出报告逐项列能力和降级。
- CLI保留render:goal/preview:start/export:pptx/export:pdf入口，新增render:project与qa:project；旧goal作为兼容输入，导出统一读取最终ProjectV2。
