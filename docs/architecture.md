# 架构决策 · 0.1.0 实验版

内容台账 → 语义计划 → 独立风格参数 → 统一构图编译器 → 元素计划 → HTML/PPTX。

1. 维护用户公开仓库固定基线 d5084d5，保留 skills/dashiai-ppt。原全局安装不变，Dawang 使用本仓库独立入口。
2. runtime/contracts 校验事实引用、硬要求、媒体裁切和能力。compiler 同时驱动三种风格与六类正文构图；没有为三风格建立三份生成器。
3. 不引入 PPTD 第二真相。sources 是文字与数据真相，media 是素材真相，content-plan 是语义计划，render-plan 派生。浏览器编辑通过 ID 写回，布局覆盖单独保存；过期对象 ID 阻断。
4. 现有 html-deck-to-pptx 许可限于 DashiAI 技能。本版新路径使用 MIT PptxGenJS；旧导出器只在保留的原技能中使用，未复制到新运行时，也未逆向修改。
5. Kimi 仓库未声明可确认的再分发许可；60份本地设计资料只公开目录、哈希及状态，不复制正文。三种适配参数与场景规则是重新编写的规则实现，原始规范与16:9适配明确区分。
6. 新运行时固定依赖并覆盖 image-size 为 2.0.3，npm audit 当前为0项。依赖更新不自动推入原技能。
7. QA区分几何、视觉、文件对象、独立渲染、客户端和用户评审。内容变化让旧报告失效；导出强制检查当前状态的几何QA。文字字体轮廓允许0.3em垂直测量余量，不能用该余量忽略实际scroll溢出。
8. 旧主题仅支持显式文字 props 绑定、原渲染与原导出。旧浏览器全部状态反向映射及媒体契约未完成，明确拒绝必需媒体的自动适配。旧样式不自动获得新路径的自适应能力。

本版有固定区域与受控比例，尚非通用自动排版引擎。内容过量由实际测量发现后，由智能体调整比例/结构或在允许时拆页。参考迁移、任意用户PPTX模板解析、完整七场景、原生数据图表及SmartArt属于后续能力。
